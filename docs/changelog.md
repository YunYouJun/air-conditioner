这里记录用得到、看得见的变化。开发细节见 [GitHub 提交记录](https://github.com/YunYouJun/air-conditioner/commits/main)。

## 未发布

### 网页版

- **3D 模式**：点「3D」，空调变成和桌面版同一个立体模型，可以拖动转一转（双击回正），还能在挂机和柜机之间切换；导风板、显示窗、指示灯、扫风、雾气和冷凝水都和平面版一致。只在打开时才下载 3D 部分，平时页面不变重；浏览器不支持时按钮会变灰。（[#184](https://github.com/YunYouJun/air-conditioner/issues/184)）
- **风速**：遥控器新增「风速」键，在自动、低风、中风、高风之间切换。低风更安静、出风更柔和，高风更有劲；小屏上的风速格跟着点亮。（[#29](https://github.com/YunYouJun/air-conditioner/issues/29)）
- **制冷、制热分别记温度**：和真的遥控器一样，制冷调到 20°C、制热调到 28°C，来回切换时各自保持。（[#39](https://github.com/YunYouJun/air-conditioner/issues/39)）
- **新遥控器**：白色圆角、按键只用图标。顶部小屏显示模式、温度、风速、扫风和声音状态；按键是电源、温度加减、制冷 / 制热，以及风速、扫风、声音。
- **扫风**：新增扫风键，开启后出风左右摆动，三股气流也会向两侧散开；导风板跟着上下摆，出风口里的导风叶片也会左右摆，关掉扫风就停在当前位置。（[#50](https://github.com/YunYouJun/air-conditioner/issues/50)）
- **长按调温**：按住遥控器的 + / − 会连续调温，越按越快，到上下限自动停下；关机时直接按制冷或制热，空调会开机并进入该模式。（[#115](https://github.com/YunYouJun/air-conditioner/issues/115)）
- **雾气**：制冷时，出风口下方会飘出几团冷雾，温度越低、风越大雾越浓。（[#70](https://github.com/YunYouJun/air-conditioner/issues/70)）
- **冷凝水**：开到 22°C 以下时，导风板边缘偶尔聚起一颗水珠，「嗒」地落下；越冷滴得越勤。睡眠和静音模式下不出声。（[#21](https://github.com/YunYouJun/air-conditioner/issues/21)）
- **「出风口吹出的小纸条」**：节能建议改为一张从出风口被风吹出来的便签，冷风是冰蓝色、暖风是暖橙色，几秒后随风飘走；同一条建议不会反复出现。改风速、声音、扫风只在遥控器小屏上显示，不再弹提示；温度到上下限时小屏抖一下。
- **遥控器悬浮窗**：在 Chrome / Edge 里点「遥控器悬浮窗」，遥控器会被「拿下来」放进一个始终置顶的小窗，切到别的应用也能调温；原位留一个挂座，点「放回」就回来。其他浏览器仍会打开独立遥控器窗口。
- **能效标识**：按现行 GB 21455-2019 显示 5 级等级，补上能效信息码（二维码），并按实物比例缩小，不再盖住半个机身。（[#114](https://github.com/YunYouJun/air-conditioner/issues/114)）
- **使用说明书**：页面底部可以展开一份空调「说明书」，里面有常见问题和「26 度空调节能倡议」。（[#125](https://github.com/YunYouJun/air-conditioner/issues/125)）
- 网站上的空调和 Vue / React 组件、网页组件现在是同一个，新功能会同时出现在各处；显示窗的模式图标和 °C 也统一成了组件的样式。
- 图标统一换成 Material Design Icons，太阳等图标更清晰。
- 页面更轻：去掉了 MUI 等不再需要的依赖，脚本体积减少约 30%。
- 修复：暗色模式下演示页标题看不清；独立遥控器现在也能关掉空调的声音。（[#180](https://github.com/YunYouJun/air-conditioner/pull/180)）

### macOS 菜单栏小空调（CuteAC）

- **室温**：把这台 Mac 当作空调所在的房间，显示 CPU 温度、风扇转速和散热状态；风扇转得越快，雪花和暖风吹得越猛。只读取，不需要管理员权限。
- **柜机**：可以在挂机和柜机之间一键切换外观；柜机的出风口是一排会倾斜的百叶，桌面挂件也会变成竖长的样子。
- **风速**：自动时跟随 Mac 的风扇，也可以固定在低、中、高档；制冷和制热各自记住温度。
- **检查更新**：每天最多检查一次新版本，有新版本时在弹窗里提示下载。

### 云之彼端（Yun Home）

- 空调插件可以显示这台 Mac 的室温（仅限官方插件），并支持风速和分模式记温度。
- 已安装的插件会随 App 更新自动升级；需要新权限时，会先征求你的同意。

## v0.3.0（2026-10-17）

- **声音键**：标准、睡眠、静音三种声音模式；风声更柔和、更安静，开机一段时间后会自动变小。（[#179](https://github.com/YunYouJun/air-conditioner/pull/179)）
- **电脑降温**：在 Chrome / Edge 里打开后，电脑忙起来时空调会自动开启制冷。
- **新外观**：3 : 1 的长款机身、立体光影，以及开机自检动画。
- 动效更顺滑，并支持系统的「减弱动态效果」。（[#176](https://github.com/YunYouJun/air-conditioner/pull/176)）
- 修复：手机上空调机身被压扁的问题。（[#177](https://github.com/YunYouJun/air-conditioner/pull/177)）
