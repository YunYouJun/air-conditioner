## 云空调 CuteAC 0.4.0

云空调现在可以通过 Home Assistant 控制真实空调，并与“云之彼端”Home App 共用已有绑定。

### 新增

- **Home Assistant 接入**：复用 Home 0.2.0 的 HomeDeviceKit、设备绑定与 macOS 钥匙串令牌。已在 Home 绑定的 HA 空调无需再次登录米家。
- **多台空调切换**：在菜单栏弹窗顶部选择客厅、主卧、次卧等空调，分别控制开关、制冷/制热和目标温度；桌面空调也显示当前房间。
- **跨 App 状态同步**：CuteAC 与 Home 分别订阅 HA 状态，一边操作后另一边自动更新；各自选择的设备互不影响。

### 改进

- 调温遵循设备的温度范围与步进，支持 0.5°C；真实室温使用空调传感器读数。
- Home 更新房间或删除绑定后，CuteAC 自动刷新设备目录，也可手动刷新或重新连接。
- 断线、缺少令牌、设备不可用或温标不支持时禁用真实设备控制；虚拟空调保留自己的设置。
- 演示录制固定使用虚拟空调，避免演示脚本控制真实设备。

### 开始使用

1. 运行 [Home 0.2.0](https://github.com/YunLeFun/home/releases/tag/macos-v0.2.0)，完成 Home Assistant 空调绑定。
2. 下载 `CuteAC-0.4.0.zip`，解压并打开 `CuteAC.app`。
3. 在“当前空调”中选择设备。首次访问共用钥匙串令牌时，按 macOS 提示手动授权。

已完成三台小米空调切换，以及次卧开关、调温和 CuteAC → Home 自动同步联调；测试后恢复了原设置。

本次仓库统一发布 `0.4.0`：包括 CuteAC、core/Vue npm 包和 Home 设备插件；Home Assistant 真机接入与共享绑定为原生 App 功能。需要 macOS 14 或更高版本。本版 App 使用 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
