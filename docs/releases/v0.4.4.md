## 云空调 CuteAC 0.4.4

CuteAC 首次完成 Apple 公证与票据装订，并补充 Home Assistant 不可用状态提示；网页端同期发布独立悬浮挂件包与独立文档站。

- Developer ID 构建启用 Hardened Runtime，并通过 `notarytool` 完成 Apple 自动公证、票据装订及 `spctl` 校验；全部产物就绪后再统一发布 GitHub Release。解压后可直接打开，无需再到“隐私与安全性”手动放行。
- 当已绑定的 Home Assistant 空调暂时不可用时，菜单栏弹窗与读数区域会清晰显示不可用状态。
- 新增独立悬浮挂件包 `@yunlefun-home/air-conditioner-widget`，支持 npm 与固定版本 CDN `<script>` 接入；DOM 重新挂载时保留空调状态，优化重连动效、音频缓存、暗色小纸条与冷雾渲染（[#186](https://github.com/YunYouJun/air-conditioner/pull/186)、[#187](https://github.com/YunYouJun/air-conditioner/pull/187)、[#188](https://github.com/YunYouJun/air-conditioner/pull/188)、[#191](https://github.com/YunYouJun/air-conditioner/pull/191)、[#192](https://github.com/YunYouJun/air-conditioner/pull/192)）。
- 网页遥控器改用 Web Audio 即时播放按键音效，减少 3D 挂机与柜机切换闪烁，并上线独立文档站 [docs.ac.yunyoujun.cn](https://docs.ac.yunyoujun.cn)（[#185](https://github.com/YunYouJun/air-conditioner/pull/185)、[#189](https://github.com/YunYouJun/air-conditioner/pull/189)、[#190](https://github.com/YunYouJun/air-conditioner/pull/190)）。

下载 `CuteAC-0.4.4.zip`，解压后替换“应用程序”中的 `CuteAC.app`。需要 macOS 14 或更高版本；建议搭配 [Home 0.2.2](https://github.com/YunLeFun/home/releases/tag/macos-v0.2.2)。已完成 Developer ID 签名与 Apple 公证。

沿用仓库统一版本规则，`@yunlefun-home/air-conditioner-core`、`@yunlefun-home/air-conditioner`、`@yunlefun-home/air-conditioner-widget` npm 包与 Home 插件 `air-conditioner.yunplugin` 同步发布 0.4.4。
