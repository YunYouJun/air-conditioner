## 云空调 CuteAC 0.4.3

修复多屏菜单栏弹窗首次打开时的位置偏移、跳动和裁切，优化小数温度显示。

- 从副屏菜单栏打开时，显示前就确定目标屏幕、锚点和内容尺寸，避免先出现在错误位置再跳回。
- 修复挂机、柜机切换及内容高度变化时的裁切；内容超过屏幕可用高度时可滚动查看，兼容系统滚动条设置。
- 温度如 `25.5°C` 的小数和小数点使用较小字号，单位保持在数字右上角；调整电源按钮与温度区域的对齐。
- 沿用同一 Developer ID 签名，保留现有 Home Assistant 绑定、多台空调切换和 Home ↔ CuteAC 状态同步。

下载 `CuteAC-0.4.3.zip`，解压后替换“应用程序”中的 `CuteAC.app`。需要 macOS 14 或更高版本；建议搭配 [Home 0.2.2](https://github.com/YunLeFun/home/releases/tag/macos-v0.2.2)。已使用 Developer ID 签名，尚未进行 Apple 公证。

沿用仓库统一版本规则，core/Vue npm 包和 Home 插件同步发布 0.4.3。本版还包含此前已合入 main 的网页改进：切换 2D/3D、挂机/柜机时保持页面位置，以及 3D 挂机右侧的能效标识。
