## 云空调 CuteAC 0.4.1

修复 0.4.0 发布包在下载、解压后因找不到资源而闪退的问题。

- 使用 Xcode 构建后端生成资源访问代码，并从相同后端定位可执行文件和资源，确保字体与三维模型随 App 一起加载。
- 打包后严格校验代码签名；CI 与发布流程将 App 移到独立目录，临时隐藏构建缓存，验证启动及挂机、柜机的六张状态图。
- 保留 Home Assistant 共享绑定、多台空调切换与 Home ↔ CuteAC 状态同步。升级不需要重新绑定设备；macOS 可能再次询问钥匙串访问授权。

下载 `CuteAC-0.4.1.zip`，解压后将 `CuteAC.app` 放入“应用程序”。建议搭配 [Home 0.2.1](https://github.com/YunLeFun/home/releases/tag/macos-v0.2.1) 使用。

沿用仓库统一版本规则，core/Vue npm 包和 Home 插件同步发布 0.4.1；本次修复针对原生 App 打包，Web 功能不变。需要 macOS 14 或更高版本。App 使用 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
