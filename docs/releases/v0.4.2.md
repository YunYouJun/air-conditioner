## 云空调 CuteAC 0.4.2

减少切换多台 Home Assistant 空调和升级后的重复钥匙串授权，继续复用 Home 中已有的 HA 绑定。

- 升级 HomeDeviceKit：同一 HA 地址的多台空调共用本次会话的一次令牌读取，切换设备和自动重连不再反复请求钥匙串访问。
- 取消或拒绝授权后暂停重复读取，点击“重新连接”再试；Home 更新令牌后也可通过此按钮读取新值。
- 发布包与 Home 使用同一个 Developer ID Application 证书（团队 `QT792GAY4C`）；CI 验证固定代码身份和独立启动，签名配置缺失时停止发布。
- 保留现有 HA 绑定、三台及更多空调切换、房间映射和 Home ↔ CuteAC 状态同步；无需重新登录米家或复制令牌。

下载 `CuteAC-0.4.2.zip`，解压后替换“应用程序”中的 `CuteAC.app`。建议搭配 [Home 0.2.2](https://github.com/YunLeFun/home/releases/tag/macos-v0.2.2)。从旧 ad-hoc 包首次升级仍可能需要对两款 App 分别选择“始终允许”。

沿用仓库统一版本规则，core/Vue npm 包和 Home 插件同步发布 0.4.2；本次修复针对原生 App 连接和签名。需要 macOS 14 或更高版本。已使用 Developer ID 签名，尚未进行 Apple 公证。
